# CS 224L Web Technologies Portfolio

This repository contains the Web Technologies lab portfolio of **Maroosh Ishfaq**, a Data Science student in the Department of Computer Science at the University of Engineering & Technology, Peshawar.

The main lab work is in [`Lab Task`](Lab%20Task/), including a personal profile, official 5th Semester BS Data Science schedule, semantic navigation, a registration form, a validated contact form, and a custom 404 page.

## GitHub Pages

The repository root contains the GitHub Pages landing page. In GitHub repository **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and the `/ (root)` folder, then save. After the deployment completes, open the Pages URL shown in the same settings screen and check all links.
